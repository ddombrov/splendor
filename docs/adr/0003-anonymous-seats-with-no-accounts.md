# Players are anonymous and hold a seat through their browser

There are no accounts. A browser holds a private token for its seat in a game, and the game code is the only way in. Same-device and AI games can only be resumed from the browser that created them, and only online games can be joined from another browser. The cost is that a player cannot continue the same game from a different device, which we accepted to avoid sign-up.
